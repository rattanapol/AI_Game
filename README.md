# 🖐️ AI Hand Ninja - เกมตรวจจับท่าทางผ่านเว็บแคมด้วย AI

เกมเว็บอาร์เคดที่ควบคุมด้วยมือผ่านกล้องเว็บแคมแบบเรียลไทม์ โดยใช้ **Google MediaPipe Hand Landmarker** ควบคู่กับ **Optical Motion AI** และรองรับการเล่นด้วยเมาส์/ทัชสกรีน

## 🎮 วิธีเล่น
- **☝️ ชี้นิ้ว / กวาดมือ (Slice):** ขยับปลายนิ้วชี้หรือกวาดมือผ่านผลไม้ (`🍎 🍉 🍊 🍓 🍍`) เพื่อทำคะแนนและสะสมคอมโบ
- **🤏 จีบนิ้ว / กำมือ (Grab):** จีบนิ้วโป้งชนนิ้วชี้ หรือกำมือเมื่ออยู่ทับ **ดาวโบนัส (`⭐`)** เพื่อรับคะแนนพิเศษ `+50`
- **💣 หลบระเบิด:** ระวังอย่าให้มือโดนลูกระเบิด มิฉะนั้นจะถูกลดคะแนน `-30` และรีเซ็ตคอมโบ

## 🚀 การรันในเครื่อง (Local Development)
```bash
npm start
```
จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:3000`
